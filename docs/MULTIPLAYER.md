# 멍뭉고치 멀티플레이 설계

## 1. 공간 구조

| 공간 | 누가 만나나 | 인원 | 글자 채팅 | 파일 |
| --- | --- | --- | --- | --- |
| 마이룸 | 친구끼리 (친구 코드로 맺은 사이) | 제한 없음 | 모두와 친구일 때만 | `server/rooms.js` |
| 멍뭉 놀이터 | **누구나** (공개 광장) | 채널당 20마리 | **없음** (스티커·정해진 문장·몸짓만) | `server/plaza.js` |
| 2인 협동 게임 | 놀이터의 같은 놀이 장소에서 만난 두 명 | 2 | 없음 | `server/coop/`, `shared/coop/` |

놀이터 채널은 친구가 있는 곳 → 사람이 많은 곳 → 새 채널 순서로 배정해요.

## 2. 공통 원칙: 입력 → 상태 → 렌더링 (한 방향)

```
[내 화면] 버튼/조이스틱 ──입력(input)──▶ [서버] 게임 규칙이 상태(State) 갱신
                                            │
[두 사람 화면] ◀──상태 + 이벤트 방송──────────┘
      └─ 받은 상태만 보고 그려요 (화면은 상태를 직접 바꾸지 않아요)
```

- **게임 규칙은 순수 함수**로 `shared/coop/<게임>.js`에 둬요. 서버는 판정에, 브라우저는 게이지 같은 화면 표시에 같은 코드를 써요.
- 판정은 항상 서버가 해요. 브라우저는 반응이 빨라 보이도록 내 강아지 애니메이션만 먼저 보여 줘요.
- 시간은 서버 기준 (`now`를 상태와 같이 보내고, 브라우저가 시계 차이를 보정해요).

### 게임 규칙 모듈 인터페이스

```js
export const myGame = {
  id: 'ribbon',
  init({ now }) → state,                           // 새 판 시작
  input(state, { role, input, now }) → events[],   // 한 사람의 입력 반영 (state를 갱신)
  tick(state, now) → events[],                     // 시간 흐름 (20Hz)
  reward(state) → { coins, item },                 // 끝났을 때 보상
};
// state.status: 'play' | 'clear' | 'timeout'
```

### 공통 상태 (모든 협동 게임)

| 필드 | 뜻 |
| --- | --- |
| `game` | 게임 id |
| `status` | `play` / `clear` / `timeout` |
| `startedAt`, `endsAt` | 서버 시각 (타이머) |
| 게임별 필드 | 예: 리본 풀기는 `stage`, `stageStart`, `taps` |

### 역할 (Player Role)

- `p1`: 놀이 장소에서 **먼저 기다린 사람** (방장, 화면 왼쪽)
- `p2`: 나중에 와서 짝이 된 사람 (손님, 화면 오른쪽)
- 서버는 입력을 보낸 사람의 역할을 스스로 찾아요. 브라우저가 역할을 속일 수 없어요.

### 소켓 이벤트

| 이벤트 | 방향 | 내용 |
| --- | --- | --- |
| `coop:queue {game}` | 브라우저 → 서버 | 놀이 장소에서 "같이 하기". 기다리는 사람이 있으면 바로 시작 |
| `coop:queue {game, waiting}` | 서버 → 채널 | 누가 기다리는지 알림 (놀이터 화면에 표시) |
| `coop:start {sid, role, players, state, now}` | 서버 → 두 명 | 게임 시작 |
| `coop:input {sid, input}` | 브라우저 → 서버 | 입력 |
| `coop:state {sid, state, events, now}` | 서버 → 두 명 | 상태 갱신 + 이벤트 (연출용) |
| `coop:end {sid, status, results}` | 서버 → 두 명 | 결과와 보상 |
| `coop:leave` | 브라우저 → 서버 | 그만하기 |

## 3. 놀이터 이동 동기화

- 내 강아지는 내 브라우저가 움직여요 (조이스틱 / 바닥 탭 / 방향키), 초당 10번 위치를 보내요.
- 다른 강아지는 받은 위치로 부드럽게 따라가요 (멀면 빨리, 아주 멀면 순간이동).
- 서버는 위치를 월드 크기 안으로 제한하고, 너무 잦은 전송은 버려요.
- 술래잡기처럼 닿았는지는 서버가 위치로 판정해요 (20Hz 대신 10Hz 틱).

## 4. 공개 광장 안전장치

- 글자 채팅 없음. 스티커 8종, 정해진 문장 8개, 몸짓 4종(멍!/점프/인사/빙글)만.
- 강아지를 누르면 **차단** / **신고**. 차단하면 서로 안 보이고, 소리·스티커·협동 짝짓기·친구 신청이 모두 막혀요.
- 신고는 이유를 골라서 해요. 신고한 사람은 자동으로 차단돼요.
- 24시간 안에 **서로 다른 3명**에게 신고받으면 24시간 동안 놀이터 입장 제한.
- 놀이터에서는 친구 신청을 할 수 없어요 (친구 코드를 직접 주고받아야 해요).
- 신고 기록은 `abuse_reports` 테이블에 남고, 운영자가 `/admin`(환경 변수 `ADMIN_CODE`)에서 확인해요: 신고받은 친구별로 모아 보고, 놀이터 제한(1·3·7·30일)·제한 풀기·확인 완료를 할 수 있어요. 제한하면 지금 있는 놀이터에서도 바로 나가요.

## 5. 게임 목록과 진행 상황

| 게임 | 종류 | 놀이터 위치 | 규칙 파일 |
| --- | --- | --- | --- |
| 술래잡기 | 놀이터 전체 (2명 이상) | 오른쪽 위 마당 | `server/plaza.js` |
| 멍멍 축구 | 놀이터 팀 경기 (핑크/파랑, 2명 이상) | 오른쪽 아래 | `server/plaza.js` (서버 공 물리) |
| 보물찾기 | 놀이터 협동 (몇 명이든) | 연못 아래 모래밭 | `server/plaza.js` |
| 으쌰으쌰 대왕 리본 풀기 | 2인 동기화 | 왼쪽 아래 선물 상자 | `shared/coop/ribbon.js` |
| 깡총깡총 실시간 줄넘기 | 2인 동기화 | 왼쪽 아래 줄넘기 터 | `shared/coop/jumprope.js` |
| 영차영차 쿠션 탑 쌓기 | 2인 역할 분담 (쿠션/등반), 20Hz 실시간 | 오른쪽 가운데 | `shared/coop/cushion.js` |
| 우당탕탕 수제 간식 공장 | 2인 역할 분담 (굽기/토핑) | 오른쪽 가운데 | `shared/coop/bakery.js` |
| 장난감 방 정리 정돈 | 2인 자유 협동 (드래그 앤 드롭) | 왼쪽 위 | `shared/coop/tidy.js` |
| 멍뭉 패션쇼 | 놀이터 무대 (2~6명 + 구경하는 누구나 응원) | 위쪽 가운데 | `server/plaza.js` (`FASHION`) |

### 멍뭉 패션쇼 흐름
참가(2~6명) → 8초 카운트다운 → 주제 발표 + 45초 옷 갈아입기(놀이터 안 작은 옷장) → 한 명씩 7초 무대(조명 아래 정면 포즈)
→ 놀이터의 누구나 하트·별·반짝으로 응원(한 친구에게 3번까지, 나 자신은 안 돼요) → 결과: 모두 참가 코인, 응원 1등은 "오늘의 스타" 코인 더.
글자 없이 정해진 응원만 쓰고, 차단한 친구에게는 응원을 못 보내요. 배지 "패션쇼 스타"(1등 3번).

## 6. 서버 부하

놀이터 위치는 0.1초마다 채널별로 한 묶음(`plaza:snap`)으로 보내요. 20마리가 모두 움직여도 한 사람이 받는 메시지는 초당 10개 남짓이에요.
`node --no-warnings scripts/loadtest.js 400 15` 로 직접 잴 수 있어요 (가짜 강아지들이 초당 10번씩 위치를 보내며 뛰어다녀요).

| 동시 접속 | 서버 CPU (한 코어 기준) | 메모리 | 응답 p95 | 한 명당 받는 양 |
| --- | --- | --- | --- | --- |
| 100마리 (5채널) | 5% | 100MB | 0.8ms | 초당 약 3.6KB |
| 200마리 (10채널) | 9% | 115MB | 1.1ms | 초당 약 3.8KB |
| 400마리 (20채널) | 15% | 161MB | 1.1ms | 초당 약 3.9KB |

(개발 컨테이너에서 잰 값이에요. NAS CPU가 더 느리면 CPU %는 2~4배쯤 높게 나와도 충분히 여유 있어요.
실제로 먼저 한계가 오는 건 집 인터넷 업로드 속도예요: 400명이면 약 12Mbps, 100명이면 약 3Mbps.)

새 협동 게임 추가 방법: `shared/coop/<게임>.js`에 규칙 모듈 → `server/coop/index.js`의 `GAMES`에 등록 →
`public/js/coop-<게임>.js`에 렌더러(`onState`, `destroy`) → `public/js/coop.js`의 `RENDERERS`에 등록 →
`shared/data.js`의 `COOP_GAMES`, `PLAZA_SPOTS`에 설정과 놀이 장소 추가.
