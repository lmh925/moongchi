## 1. 지금 게임 진단: 세 기둥 기준

### 1-1. 기둥별 점검

| 기둥 | 지금 있는 것 | 잘된 점 | 부족한 점 |
| --- | --- | --- | --- |
| 🥚 **육성** (다마고치) | 포만감·청결도·애정도, 똥, 사료/간식, 성장 3단계, 성격 6종, 개인기, 학교, 참을성 게이지, 소원 말풍선 | 방치해도 벌이 없는 하한선 20, 성격별 반응, "필요할 때만 보상" | 강아지가 **화면의 주인공이 아님**(작은 무대 + 긴 문서). 몸짓·표정이 단조로움. 알림(푸시)이 없어 "보고 싶어서 다시 여는" 계기가 약함 |
| 🏡 **생활·수집** (동물의 숲) | 방 꾸미기(7칸), 옷 131종, 마을(마당·카페·온천·캠핑장), 카페 손님 동물 9종, 도감, 배지, 계절 의상, 생일·달력·일기, 편지 | 수집거리 풍부, 실제 날짜 연동(생일·계절) | 동숲의 핵심인 **① 걸어 다니는 마을 ② 이웃 주민과의 관계 ③ 채집·기증 ④ 가구를 원하는 곳에 놓기 ⑤ 시즌 이벤트**가 없거나 메뉴 버튼 수준이에요. 마을이 "지도에서 누르는 메뉴"라 생활감이 없어요 |
| 🎮 **미니게임** | 멍뭉런(4맵), 간식 받기, 훈련 5과목, 줄넘기(혼자/둘이), 포토부스, 간식 파티, 놀이터 4종(술래잡기·축구·보물찾기·패션쇼), 협동 5종 | 종류가 아주 많고, 협동·실시간까지 있어요 | **15종 이상이 흩어져 있어** 어디서 뭘 하는지 찾기 어렵고, 각각이 얕아요. 줄넘기 2종, 간식 게임 2종처럼 비슷한 게 겹쳐요 |

### 1-2. 구조적인 문제 4가지

1. **기능 과잉 (feature creep)**
   - 성장 축이 10개예요: 강아지 레벨 · 성장 단계 · 재능 5종 · 훈련 과목 레벨 · 자격증 · 런 레벨 · 카페 레벨 · 친밀도 · 배지 · 칭호.
   - 아이가 "나는 지금 뭘 키우고 있지?"를 한마디로 말할 수 없어요.
2. **재화 과잉**
   - 7가지예요: 뼈다귀 코인 · 💗 · 뽑기권 · 간식 · 사료 · 학교 아이템 2종 · 런 부스터/부활.
   - 유료 상품을 넣으면 더 복잡해져요.
3. **웹페이지 구조**
   - 우리집 탭 세로 1,400px 스크롤, 탭 6개, 카드 나열.
   - 상용 육성 게임은 **한 화면 + 팝업/전용 화면** 구조예요.
4. **아트 규모 대비 품질**
   - 견종 16종 + 스페셜 6종, 아이템 191개를 코드로 그려서 양은 많지만, 하나하나가 상용 수준에 못 미쳐요.
   - 새 아트로 바꿀 때 191개를 다 다시 그리는 건 비현실적이에요 → **출시 범위를 줄이고 업데이트로 늘리는 전략**이 필요해요.

## 2. 정리안: 유지 · 강화 · 통합 · 숨김 · 추가

### 2-1. ✅ 유지하고 강화

| 시스템 | 강화 방향 |
| --- | --- |
| 돌봄 루프 (밥·빗질·쓰다듬기·똥) | 풀스크린 홈의 중심. 강아지를 직접 문지르기(빗질은 드래그), 밥그릇에 끌어다 놓기 같은 **손으로 하는 돌봄** |
| 성장 3단계 + 성격 6종 | 단계마다 **모습이 확실히 달라지는 아트**와 성장 연출(전용 컷신) |
| 방 꾸미기 | **가구 자유 배치**(격자 위 끌어다 놓기), 방 확장(유료 상품 후보) |
| 마을 | 메뉴 → **걸어 다니는 마을 맵**(집 · 광장 · 카페 · 학교 · 공원 · 바닷가) |
| 멍뭉런 | 메인 미니게임. 맵별 테마곡, 시즌 맵 추가 |
| 훈련(같이 등교) | 5과목은 유지하되 **과목 레벨 = 재능**으로 합쳐서 성장 축 하나 줄이기 |
| 오늘의 약속 + 도장판 | 리텐션 핵심. 출석 보상과 합쳐 "오늘의 할 일" 한 곳으로 |
| 캡슐 뽑기 (코인 전용) | 유지. **유료 결제와 연결하지 않아요** (4-3 참고) |
| 친구 집 방문 · 놀이터 | 유지 (아동 안전장치 그대로) |
| 둘째·셋째 입양 | 유지 (슬롯 추가는 유료 상품 후보) |
| 스페셜 캐릭터 이스터에그 | 유지. "원조 코드"는 가족 전용이라 공개 버전에서는 숨겨요 |

## 4. 수익화 설계 (아동 대상 기준)

### 4-1. 전제: 이 게임은 Google Play에서 "아동 대상 앱"이에요

초등학생이 주 대상이라 Play Console의 타겟 연령에 13세 미만이 포함되고, **가족 정책(Families Policy)** 을 따라야 해요.
- 광고는 **Google Play 자체 인증 광고 SDK만**, **맞춤 광고 금지** ([Families Self-Certified Ads SDK 정책](https://support.google.com/googleplay/android-developer/answer/12918983)). AdMob은 아동 대상 설정(child-directed)으로 쓸 수 있고, 인증받지 않은 광고 소스는 AdMob이 자동으로 막아요 ([AdMob 아동 대상 설정](https://support.google.com/admob/answer/6223431)).
- 맞춤이 아닌 광고라서 **광고 단가가 일반 게임보다 낮아요.** 그래서 광고 수익만 기대하기보다 **부모님이 결제하는 "광고 제거"와 꾸미기 상품**을 주력으로 봐요.
- 결제 전에는 **보호자 확인 단계**(간단한 계산 문제)를 둘 것을 권해요. 미성년자 결제는 보호자가 취소할 수 있어서 환불 분쟁을 줄이는 장치예요.

| 보상형 (주력) | 미니게임 보상 2배 · 무료 뽑기 +1 · 학교 바로 끝내기 · 멍뭉런 이어 달리기 · 사료 바로 채우기 | 하루 최대 횟수 제한 |
| 전면 | 미니게임 **끝난 뒤** 결과 화면에서만 | 3분에 1번 이하, 첫날은 없음, 광고 제거 시 없음 |

## 5. 기술 구조: 앱으로 만들기

| 항목 | 제안 | 이유 |
| --- | --- | --- |
| 앱 포장 | **Capacitor** (안드로이드 네이티브 껍데기 + 지금의 웹 게임) | 기존 계획의 TWA(PWA 포장) 방식은 **AdMob 광고를 화면 안에 띄울 수 없어요** ([참고](https://kiwix.lema.org/stackoverflow.com_en_all_2023-11/questions/60899706/is-there-a-way-to-add-admob-to-a-trusted-web-activity)). Capacitor는 AdMob · Play 결제 · 로컬 알림 · 진동을 네이티브로 쓸 수 있어요 |
| 화면 엔진 | 강아지·방은 **PixiJS(WebGL)** 로, 메뉴는 지금처럼 HTML | 고해상도 일러스트와 뼈대 애니메이션을 부드럽게 그리려면 필요해요 |
| 캐릭터 애니메이션 | **부품(컷아웃) 애니메이션을 코드로** | 머리·귀·몸·다리·꼬리 그림을 받으면 제가 숨쉬기·걷기·꼬리 흔들기·뒹굴기를 코드로 움직여요. Spine 같은 유료 편집 프로그램 없이 가능해요 |
| 결제 검증 | 서버에서 Google Play Developer API로 영수증 확인 | 해킹으로 아이템을 받는 것 방지, 기기를 바꿔도 구매 복원 |
| 서버 | 출시 전 **NAS → 클라우드(Fly.io 설정이 이미 있어요)** 권장 | 스토어 앱은 집 정전·공유기 문제로 서버가 꺼지면 리뷰가 바로 나빠져요. 지금 NAS 그대로도 시작은 가능해요 (결정 필요) |
| 오프라인 | 그림·소리 파일은 앱 안에 포함 | 첫 실행이 빠르고 데이터 사용량이 적어요 |

## 6. 아트 · 음악 제작 방식

- **아트:** GPT(이미지 생성)로 만들고, 결과물을 받아 제가 자르고·정리하고·움직이게 연결해요. 프롬프트는 `docs/prompts/ART_GPT.md`에 있어요.
  1. 스타일 시안 3종 → 하나 고르기
  2. 기준 견종 1종(코기) 전체 세트 → 게임에 넣어 움직임 확인
  3. 나머지 7종 → 배경·UI·아이콘
- **음악:** Suno로 만들고, 결과물을 받아 제가 끊김 없는 반복 지점 편집·음량 맞추기·게임 연결을 해요. 곡 목록과 프롬프트는 `docs/prompts/MUSIC_SUNO.md`에 있어요.
  - 총 23곡: 배경음 16곡(멍뭉런 맵별 4곡 포함) + 이벤트 곡 3곡 + 짧은 축하음 4개
  - 효과음 중 강아지 소리(짖기·냠냠·낑낑)는 실제 소리 샘플로 바꾸는 걸 권해요. 버튼·UI 효과음은 지금의 합성음을 다듬어 써도 충분해요.
