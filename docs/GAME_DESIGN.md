# 멍뭉고치 2.0 게임 기획서 — 할거리 설계 (제안 v1)

> 목표: 초등학생이 **매일 10~20분씩, 몇 달 동안** 다시 열고 싶은 게임.
> 앞선 문서(`PLAYSTORE_PLAN.md`)는 화면 구조·수익화·기능 정리 위주였고, "무엇을 하며 노는가"는 이 문서에서 처음 설계해요.

## 1. 레퍼런스에서 가져올 것

| 게임 | 핵심 재미 (아이들이 계속 하는 이유) | 멍뭉고치에 가져올 것 |
| --- | --- | --- |
| **닌텐독스** | 손가락으로 직접 만지는 감촉 · 내 말을 알아듣는 개인기 · 산책 중 뜻밖의 선물 · 대회 컵 모으기 | **손으로 하는 돌봄**(문지르기·거품 목욕·공 던지기), **개인기 가르치기**, **산책 선물**, **주간 대회** |
| **동물의 숲** | 실제 시간과 계절 · 매일 조금씩 바뀌는 마을 · 이웃 주민과의 관계 · 채집과 박물관 · 집 꾸미기 · "내일은 뭐가 있을까" | **매일 바뀌는 가게·날씨·주민 부탁**, **채집 → 박물관 기증**, **가구 자유 배치**, **계절 이벤트** |
| **토카보카** | 정답도 실패도 없는 자유 놀이 · **누르면 다 반응함** · 숨은 비밀 찾기 · 역할놀이 | **놀이 방 모드**(모든 물건이 반응), **숨은 비밀 30개**, **역할놀이 장소**(카페·미용실·동물병원 놀이) |
| **단순 미니게임** | 1~2분 짧은 한 판 · 최고 기록 · 오늘의 도전 | **미니게임 8종**(멍뭉런 등) + **오늘의 도전** |

**한 줄 정리:** 닌텐독스의 *손맛*, 동물의 숲의 *매일 새로움*, 토카보카의 *자유로움*, 미니게임의 *짧은 도전*을 한 강아지 이야기로 묶어요.

## 2. 시간 단위별 놀이 루프

| 단위 | 아이가 하는 것 | 느끼는 것 |
| --- | --- | --- |
| **30초** | 강아지를 쓰다듬고, 공을 던지고, 밥을 끌어다 주기 | 만지면 반응한다 (손맛) |
| **5분 (한 번 접속)** | 돌봄 → 산책 1번 → 미니게임 1판 → 주운 것 기증 또는 옷 입히기 | 오늘도 뭔가 생겼다 |
| **하루** | 할 일 3개 · 산책 선물 · 주민 부탁 · 가게 새 물건 · 날씨 이벤트 | 내일 또 와야지 |
| **일주일** | 주간 대회(컵) · 떠돌이 상인 방문 · 주간 미니게임 순위(친구끼리) | 이번 주 목표가 있다 |
| **한 달** | 계절 이벤트 · 한정 옷·가구 · 계절 채집물 | 지금만 할 수 있다 |
| **몇 달** | 성장(아기→어른) · 개인기 20개 마스터 · 도감 완성 · 마을 발전 · 둘째 입양 | 내가 키웠다 |

## 3. 할거리 목록

### A. 손으로 하는 돌봄 (닌텐독스) — 출시 10종
| 놀이 | 손 동작 | 강아지 반응 |
| --- | --- | --- |
| 부위별 쓰다듬기 | 머리·턱·등·배 문지르기 | 좋아하는 곳이 강아지마다 달라요 (찾는 재미). 배를 문지르면 발라당 |
| 빗질 | 털 방향으로 쓸기 | 빠진 털이 날려요 → **털뭉치를 모아 인형 만들기** |
| 거품 목욕 | 비누 문지르기 → 샤워 → 부르르 털기 | 물방울이 화면에 튀어요. 깨끗해지면 반짝 |
| 밥 주기 | 사료 봉지를 기울여 붓기 | 너무 많이 부으면 넘쳐요. 냠냠 소리 |
| 간식 주기 | 손바닥에 올려 내밀기 | "앉아!"를 하면 더 기뻐해요 |
| 물 갈아 주기 | 그릇을 끌어 수도꼭지로 | 할짝할짝 |
| 공 던지기 | 스와이프로 던지기 | 물어 오고 다시 던져 달라고 졸라요 |
| 줄다리기 | 밧줄 잡고 당기기 | 으르렁(귀엽게) → 이기면 우쭐 |
| 장난감 놀이 | 장난감마다 다른 놀이 (삑삑이·인형·로프) | 장난감 취향이 있어요 |
| 낮잠 재우기 | 이불 덮어 주기 · 토닥토닥 | 쿨쿨 → 일어나면 기분 좋음 |

### B. 개인기 가르치기 (닌텐독스) — 출시 20개
- 손짓(그리기)이나 말풍선 단어로 가르쳐요. 처음엔 실수하다 점점 잘해요 (성공률이 오르는 게 보여요).
- 단계: 앉아 · 손 · 엎드려 · 빵야 · 빙글 · 점프 · 인사 · 하이파이브 · 뒷발 서기 · 노래 · 춤 · 데굴 · 숨기 · 가져와 · 기다려 …
- 배운 개인기는 대회와 사진관에서 쓰여요.

### C. 산책 (닌텐독스 + 동물의 숲 채집) — 하루 3번
- 동네 지도에서 코스를 골라요 (공원 · 바닷가 · 숲길 · 시장 · 언덕). 코스는 마을이 커지면서 열려요.
- 길에서 강아지가 **킁킁 → 땅파기 → 발견**: 꽃 · 조개 · 솔방울 · 깃털 · 화석 조각 · 잃어버린 물건(주인에게 돌려주기).
- **계절·시간·날씨마다 나오는 게 달라요** (비 오는 날 달팽이, 겨울 눈사람 단추, 밤 반딧불이).
- 가끔 **선물 상자**(옷·가구)와 다른 강아지·주민을 만나요.

### D. 마을 생활 (동물의 숲)
| 요소 | 내용 | 출시 |
| --- | --- | --- |
| 이웃 주민 | 동물 주민마다 성격·말투·생일. 부탁(심부름) 들어주기 → 친밀도 → 선물·편지 | 6명 |
| 가게 | **매일 진열이 바뀌는** 옷·가구 가게 | 2곳 |
| 박물관 | 산책에서 주운 것을 기증하면 전시돼요 (도감 + 실제 전시실) | 채집물 80종 |
| 카페 | 손님 맞이 경영 놀이 (기존 카페 이어받기) | 1곳 |
| 우체국 | 강아지·주민·친구에게서 편지와 선물 | — |
| 떠돌이 상인 | 주말에만 오는 특별 상인 (희귀 가구) | 1명 |
| 마을 발전 | 💗(소원·부탁으로 모음)로 새 장소가 열려요 | 장소 6곳 |

### E. 집 꾸미기 (동물의 숲 · 토카보카)
- **가구를 원하는 곳에 끌어다 놓기**, 돌리기, 벽에 걸기.
- 방 테마(벽지·바닥) · 방 확장(2층·마당) · 테마 세트 완성 보상.
- **사진 찍기**: 꾸민 방에서 강아지와 기념사진 → 앨범.

### F. 자유 놀이 (토카보카) — "정답 없는 놀이"
- **모든 물건이 눌린다**: 시계를 누르면 뻐꾸기, 냉장고를 열면 간식, 불을 끄면 별 무드등, 창문을 열면 새가 들어와요. 방마다 반응하는 물건 15개 이상.
- **숨은 비밀 30개**: 특정 순서로 누르면 생기는 작은 깜짝 이벤트 → "비밀 도감"에 모여요.
- **역할놀이 장소**: 강아지 미용실(털 모양 바꾸기 · 염색 · 리본), 동물병원 놀이(청진기 · 붕대 — 아프게 하지 않는 놀이), 카페 놀이. 점수 없음.
- **옷 입히기 놀이**: 가진 옷 + "입어 보기 전용 옷"까지 자유롭게.

### G. 대회 (닌텐독스) — 매주
| 대회 | 방식 | 보상 |
| --- | --- | --- |
| 어질리티 | 장애물 코스 달리기 (멍뭉런 변형) | 컵 · 트로피 가구 |
| 원반 받기 | 타이밍 맞춰 던지기 | 컵 · 원반 장난감 |
| 패션 · 개인기 쇼 | 주제에 맞는 옷 + 개인기 순서 | 컵 · 무대 의상 |
- 등급: 동 → 은 → 금 → 챔피언. 트로피는 집에 진열돼요.
- 친구끼리 주간 순위 (전체 공개 순위 없음).

### H. 미니게임 (짧은 한 판, 1~2분) — 출시 8종
| 게임 | 장르 | 비고 |
| --- | --- | --- |
| 멍뭉런 | 달리기 · 점프 | 4맵 (배경음 완성) |
| 간식 받기 | 받기 | 혼자 · 친구 |
| 줄넘기 | 리듬 · 타이밍 | 혼자 · 친구 |
| 훈련 수업 | 반응 속도 | 개인기 배우기와 연결 |
| 짝 맞추기 | 기억력 | 카드 그림 = 내가 모은 것들 |
| 강아지 찾기 | 숨은그림 | 놀이터 그림에서 우리 강아지 찾기 |
| 뼈다귀 퍼즐 | 퍼즐 | 하루 한 판 "오늘의 퍼즐" |
| 꼬리 리듬 | 리듬 | 배경음에 맞춰 꼬리 흔들기 |
- **오늘의 도전**: 매일 한 게임에 작은 목표 ("멍뭉런 간식 50개") → 보상.

## 4. 성장 구조 (한 줄로 말할 수 있게)

> **"강아지와 친해질수록(유대 레벨) 마을이 커지고, 할 수 있는 게 늘어나요."**

- **핵심 축 1개: 유대 레벨** (모든 놀이가 유대 경험치를 줘요) → 성장 단계, 개인기 슬롯, 산책 코스, 대회 등급이 여기서 열려요.
- **보조 축: 수집률 · 마을 발전(💗)**. 이전 버전의 성장 축 10개(재능·과목 레벨·런 레벨·카페 레벨 …)는 이 셋으로 합쳐요.

## 5. 매일 다시 오는 이유
1. **강아지가 나를 기다려요**: 로컬 알림 (예: "콩이가 공을 물고 문 앞에 앉아 있어요") — 하루 최대 2번, 밤 9시~아침 8시엔 보내지 않아요.
2. 오늘의 할 일 3개 + 도장판 (하루 빠져도 도장은 그대로)
3. 산책 3번 (오늘은 뭐가 나올까)
4. 가게 새 진열 · 주민 부탁 · 날씨 이벤트
5. 주간 대회 · 주말 떠돌이 상인
6. 계절 이벤트와 한정 아이템

## 6. 아이와 부모를 위한 원칙
- **벌 없음**: 오래 안 와도 아프거나 떠나지 않아요 (시무룩하다가 반겨요).
- **글자 적게**: 아이콘·그림·소리로 알 수 있게. 저학년도 할 수 있게.
- **건강한 시간**: 30분쯤 놀면 강아지가 하품하며 "조금 쉬었다 또 놀자"고 해요 (막지는 않아요). 부모님이 좋아하는 장치예요.
- **돈으로 이기지 않기**: 유료 상품은 꾸미기·편의(광고 제거)만. 대회·도감·진행은 돈과 무관해요.
