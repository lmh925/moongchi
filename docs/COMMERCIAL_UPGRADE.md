# 멍뭉고치 상용화 수준 개선안 (v0.2)

> 게임 개발사 관점에서 디자인 · UI/UX · 게임성 · 시스템 · 사운드를 처음부터 끝까지 살펴보고,
> "아이들이 매일 열고 싶은, 앱스토어에 올려도 손색없는 게임"이 되려면 무엇을 바꿔야 하는지 정리했어요.
> 이 문서의 **1차 실행 항목(✅)** 은 이번 작업에서 실제로 구현했어요.

## 0. 한 줄 진단

**콘텐츠 양은 이미 상용 게임급, 손맛·분위기·안내는 아직 프로토타입급.**

멍뭉고치에는 돌봄, 학교, 훈련 미니게임 5종, 러너, 놀이터 MMO, 협동 게임 5종, 거래, 가족 계승, 카페,
온천, 캠핑, 일기, 달력, 도감, 배지까지 들어 있어요. 기능은 충분해요. 하지만 처음 켠 아이가 느끼는 건 기능 목록이
아니라 **"화면이 살아 있나, 누르면 기분 좋나, 소리가 예쁜가, 뭘 해야 할지 알겠나"** 예요. 이 네 가지가 상용 게임과의
차이를 만들어요.

| 영역 | 현재 수준 | 상용 기준 | 차이 |
| --- | --- | --- | --- |
| 캐릭터 아트 | 코드로 그린 16비트 픽셀, 견종 다양, 정면/측면 | 감정 표현이 풍부하고 상태가 몸짓으로 보임 | 중 |
| 배경/월드 | 방 1장, 창밖 항상 낮 | 실제 시간 낮/밤, 날씨·계절이 창밖에 보임 | **큼** |
| UI 정보 구조 | 우리집 탭에 카드 12개 세로 나열 | 핵심 행동 1탭, 나머지는 단계적으로 노출 | **큼** |
| 피드백(손맛) | 토스트·말풍선 위주 | 수치 변화가 눈에 보이고, 누르면 진동·튀는 연출 | 중 |
| 첫 경험(FTUE) | 글 많은 안내 창 + 창이 여러 개 겹쳐 뜸 | 손가락 안내로 3번 눌러 보면 이해 | **큼** |
| 배경음 | 8마디 반복곡 2개(+러너 4곡), 원음 그대로 | 장면마다 테마곡, A/B 구성, 화음·리듬·공간감 | **큼** |
| 효과음 | 22종, 레벨업 팡파르를 48곳에서 "성공"으로 재사용 | 행동마다 고유한 소리, 큰 보상만 큰 소리 | 중 |
| 설정 | 음소거 버튼 하나 | 배경음/효과음 따로 조절, 진동 끄기 | 중 |
| 시스템/밸런스 | 꼼꼼함 (하한선 20, 연타 방지, 거래 안전장치) | — | 작음 |

## 1. 디자인 — 캐릭터 · 월드

### 1-1. 캐릭터 (강아지)
**잘된 점**: 견종별 실루엣이 분명해요(코기 귀, 비숑 털뭉치, 푸들 곱슬). 성장 단계에 따라 크기와 털이 달라지고,
꾹 누르면 말랑 찌그러졌다가 폴짝 뛰는 반응도 귀여워요.

**문제점**
- 기분이 **눈썹(sad)** 하나로만 보여요. 배고픔·지저분함·외로움이 패널 숫자를 봐야만 보여요.
- 가만히 있을 때 하는 행동이 "걷기/정면 보기/낮잠" 세 가지뿐이라 금방 단조로워져요.
- 밤에도 낮과 똑같이 돌아다녀요.

**개선안**
- ✅ **욕구 말풍선**: 배고프면 🍖, 지저분하면 냄새 선·파리, 심심하면 💗 생각 풍선이 머리 위에 떠요. 숫자를 안 봐도 "뭘 해 줘야 할지" 보여요.
- ✅ **혼자 노는 몸짓 늘리기**: 하품, 기지개, 꼬리 쫓기, 킁킁 냄새 맡기, 뒹굴기, 앉아서 기다리기. 성격마다 자주 하는 몸짓이 달라요.
- ✅ **기분 좋을 때 반짝**: 세 수치가 모두 높으면 가끔 반짝이가 퐁퐁 올라와요.
- ✅ **밤에는 졸려요**: 밤 10시~아침 7시에는 낮잠을 훨씬 자주 자고 침대로 가요.
- (2차) 스프라이트 시트 교체 구조는 이미 있어요(`buildDog`). 전문 아티스트 에셋으로 갈 때 **감정 6종 × 포즈 10종** 표를 기준으로 발주하세요.

### 1-2. 월드 (방 · 창밖)
**문제점**: 창밖이 언제나 맑은 낮이에요. 아이가 밤 9시에 켜도, 눈 오는 날 켜도 똑같아요. "내 강아지가 진짜 나와 같은 시간을 사는 느낌"이 돌봄 게임의 핵심인데 그게 빠져 있어요.

**개선안**
- ✅ **실시간 낮/밤 (한국 시간)**: 새벽 → 낮 → 노을 → 밤 하늘. 밤에는 별이 반짝이고 달이 떠요.
- ✅ **방 조명**: 노을엔 따뜻한 주황빛, 밤엔 방이 어두워지고 창문과 강아지 주변만 은은하게 밝아요.
- ✅ **계절 날씨**: 겨울엔 창밖에 눈, 봄엔 꽃잎, 가을엔 낙엽, 여름엔 가끔 소나기. 날짜로 정해져서 친구 집도 같은 날씨예요.
- (2차) 가구 자유 배치, 방 확장(2층·마당).

## 2. UI / UX

### 2-1. 정보 구조
**문제점** (우리집 탭, 세로 1,400px)
1. 이름·견종 → 수치 3줄 → 레벨 → 성장 → 생일 → **돌봄 버튼** → 뉴스 → 일기 → 마을 → 약속 → 강아지들 → 파티 → 친구 순서예요.
   가장 자주 누르는 **돌봄 버튼이 화면 아래쪽 탭바에 가려질 때가 있어요.**
2. 다른 탭에 가면 강아지 상태(배고픈지 등)를 전혀 알 수 없어요.
3. 꾸미기 탭은 98개 아이템이 다 펼쳐져 있고 절반 이상이 잠긴 칸이라, 정작 "내가 가진 옷"을 찾기 어려워요.

**개선안**
- ✅ **무대 위 HUD**: 강아지 화면 왼쪽 위에 🍖✨💗 작은 게이지 3개를 항상 띄워요. 어느 탭에 있든 상태가 보여요. 수치가 오르면 게이지가 반짝, 낮으면 아이콘이 콩닥콩닥 뛰어요.
- ✅ **우리집 탭 순서 재배치**: 돌봄 버튼 4개를 패널 맨 위로. 수치·레벨 → 오늘의 약속 → 마을 → 나머지 순서.
- ✅ **꾸미기 필터**: [전체 · 가진 것 · 살 수 있는 것] 칩. 기본은 "전체"를 유지하되 한 번 누르면 바로 내 옷장만 볼 수 있어요.
- (2차) 탭 6개 → 5개 통합(알림장+친구 일부를 "내 소식"으로), 홈 화면 카드는 접기/펼치기.

### 2-2. 손맛 (Juice)
- ✅ 버튼을 누르면 살짝 눌렸다 튀어 오르는 탄성, 탭을 바꾸면 패널이 부드럽게 올라와요.
- ✅ 진동(지원 기기): 돌봄 성공, 코인 획득, 레벨업에 짧은 진동. 설정에서 끌 수 있어요.
- ✅ 창(모달)이 열리고 닫힐 때 소리.
- (2차) 보상 받을 때 코인이 상단 코인칸으로 날아가는 연출을 모든 보상에 통일.

### 2-3. 설정
- ✅ **설정 창**: 배경음 / 효과음 음량 슬라이더(따로), 진동 켜기/끄기. 기존 "내 정보"에 같이 넣었어요.
- ✅ 음소거 버튼을 다시 켜면 "지금 장면의 곡"이 다시 나와요 (예전엔 놀이터에서도 집 음악이 나왔어요).

### 2-4. 첫 경험 (FTUE)
**문제점**: 강아지를 데려오면 "가족이 되었어요" 글 창 + 비밀번호 창 + 편지 알림이 한꺼번에 겹쳐 떠요. 4학년이 읽기엔 글이 많아요.

**개선안**
- ✅ **손가락 따라하기 튜토리얼**: 처음 데려온 날, 화면을 어둡게 하고 버튼 하나만 밝혀서 손가락이 콕콕 가리켜요.
  ① 인사 → ② 쓰다듬기 → ③ 빗질하기 → ④ 강아지 화면 누르기 → ⑤ 상태 게이지 보기 → ⑥ 밥주기. 단계마다 강아지가 실제로 반응해요 (돌봄 보상도 그대로 받아요).
  안내 중에는 가리킨 버튼만 눌려서 길을 잃지 않아요. 언제든 "건너뛰기", 내 정보 창의 "따라하기 다시 보기"로 다시 볼 수 있어요.

## 3. 게임성 · 시스템

**잘된 점** (이미 상용 수준)
- 방치해도 벌이 없는 하한선 20, 연타 방지(필요할 때만 보상), 참을성 게이지.
- 오늘의 약속 3개 + 도장판(하루 빠져도 유지) = 부담 없는 리텐션 루프.
- 거래 안전장치, 채팅 필터, 친구 코드만으로 연결 → 아동 안전 설계 훌륭해요.
- 확률 공개 뽑기, 현금 결제 없음.

**개선 제안 (2차 로드맵)**
| 우선 | 제안 | 이유 |
| --- | --- | --- |
| 1 | **주간 이벤트 캘린더**: 매주 테마(🎃 할로윈 주간, ⛄ 눈사람 주간) + 한정 소품 | 시즌 의상은 있지만 "이번 주에 할 것"이 없어요 |
| 2 | **수집 완성 보상**: 도감 세트(예: 모자 10종) 완성 시 칭호·방 장식 | 98개 아이템의 수집 동기 부여 |
| 3 | **놀이 탭 정리**: 혼자/둘이/모두 3칸 카드로 한눈에 | 지금은 세로로 길게 나열 |
| 4 | **알림 센터 통합**: 우편함·친구 요청·거래·소원을 한 곳에 | 빨간 점이 여기저기 흩어져 있어요 |
| 5 | **보호자 리포트**: 주 1회 "이번 주 우리 아이와 강아지" 요약 | 부모 신뢰 = 아동 게임의 핵심 지표 |

## 4. 사운드

### 4-1. 배경음 (BGM)
**문제점**
- 우리집 곡이 **8마디(약 20초)** 를 무한 반복해요. 10분만 켜 두면 귀에 거슬려요.
- 멜로디 + 베이스 두 줄뿐이라 소리가 얇고, 잔향이 없어 "삑삑"거리는 느낌이에요.
- 타이틀 화면은 무음, 놀이터·학교·협동 게임은 모두 같은 "play" 곡.
- 곡이 바뀔 때 뚝 끊겨요.

**개선안 ✅ (새 사운드 엔진)**
- **믹싱**: 컴프레서(소리 크기 정돈) + 리버브(방 울림) + 딜레이 + 좌우 패닝.
- **악기 5채널**: 멜로디 / 화음 패드 / 아르페지오 / 베이스 / 드럼(킥·스네어·하이햇 합성).
- **곡 구성**: A–A′–B–A 형식으로 32마디 이상, 반복감 크게 줄임.
- **장면별 테마곡 6개 신규**

| 곡 | 장면 | 분위기 |
| --- | --- | --- |
| `title` | 타이틀·가입·심리테스트 | 오르골처럼 반짝이는 왈츠 (3/4) |
| `home` | 우리집 (낮) | 느긋한 F장조 어쿠스틱 팝, 화음 패드 + 부드러운 리듬 |
| `home_night` | 우리집 (밤 9시~아침 6시) | 자장가풍, 드럼 없이 오르골 + 패드 |
| `plaza` | 멍뭉 놀이터 | 통통 튀는 셔플 리듬, 친구들과 뛰노는 느낌 |
| `school` | 훈련 수업 | 경쾌한 행진곡 |
| `play` | 미니게임·협동 | 신나는 업템포 (기존 곡 편곡) |

- **크로스페이드**: 곡이 바뀔 때 1초 동안 자연스럽게 겹쳐 넘어가요.
- **환경음**: 우리집 낮엔 가끔 새소리, 밤엔 귀뚜라미 소리 (배경음 음량을 따라가요).

### 4-2. 효과음 (SFX)
- ✅ 새 효과음: `open`/`close`(창), `tab`(탭 전환), `success`(작은 성공), `buy`(구매), `equip`(입기), `sparkle`(반짝), `cheer`(중간 축하), `guide`(따라하기 안내), `yawn`(하품).
- ✅ 레벨업 팡파르는 **진짜 큰 일**(레벨업·성장·전설 뽑기)에만. 도장·미션·새 장소 같은 중간 축하는 `cheer`로 바꿔 귀의 피로를 줄여요.
- ✅ 기존 효과음에 잔향을 살짝 입혀 덜 날카롭게.

## 5. 기술 · 운영 (참고)
- 서버 1대 + SQLite 구조는 지금 규모(반·학교 단위)에 적합해요. 동시 접속 수백 명을 넘으면 `DESIGN.md` 10장대로 Postgres + Redis.
- 사운드는 여전히 **파일 0개**(Web Audio 합성)라 첫 로딩이 가볍고 오프라인(PWA)에서도 그대로 나와요.
- 새 설정값은 모두 기기(localStorage)에 저장돼서 서버·DB 변경이 없어요.

### 확인하는 법
- 시간·날씨 미리 보기: `/?debug&hour=22&weather=snow` (hour: 0~24, weather: clear · snow · rain · petals · leaves)
- 곡 확인: `/?debug` 로 열고 콘솔에서 `(await import('/js/audio.js')).playBgm('plaza')` (곡 이름: title, home, home_night, plaza, school, play, run_*)
- 곡 데이터 점검: 콘솔에서 `__audio.check()` → 모든 마디의 멜로디 박자가 맞는지 보여 줘요.
