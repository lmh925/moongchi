# 🎵 멍뭉고치 음악 제작 가이드 (Suno)

## 먼저 알아 두기
- **Suno 유료 플랜(Pro 또는 Premier)으로 만들어야 해요.** 무료 플랜 곡은 상업적으로(앱 판매·광고 수익) 쓸 수 없어요. 구독 중에 만든 곡만 상업 이용이 허락돼요.
- 모든 곡은 **Instrumental(가사 없음)** 을 켜고 만들어요.
- 아래 **Style** 칸 내용을 그대로 복사해 Suno의 Style of Music(스타일) 칸에 붙여 넣어요. 가사(Lyrics) 칸은 비워 두세요.
- 실존 가수·게임·작곡가 이름은 넣지 않아요. 저작권 문제가 생기고, Suno도 막아요.
- 곡마다 **2개 이상 만들어 보고** 마음에 드는 것을 골라 주세요. 애매하면 둘 다 보내 주셔도 돼요.
- 길이는 1분 30초~2분 30초면 충분해요. 끊김 없는 반복(루프)은 제가 편집해요. 페이드아웃으로 끝나는 곡이면 끝부분을 잘라 반복 지점을 만들어요.
- **보내실 때:** MP3(가능하면 WAV)로 내려받아, 파일 이름을 아래 **ID**로 바꿔서 주세요 (예: `bgm_home_day.mp3`).

## 효과음은?
- **강아지 소리**(짖기·낑낑·냠냠·킁킁·하품): Suno로는 어려워요. 다음 중 하나를 권해요.
  1. ElevenLabs Sound Effects (문장으로 효과음 생성, 유료 플랜이면 상업 이용 가능 — 가입하시면 API 키로 제가 직접 만들 수 있어요)
  2. 직접 녹음 (집 강아지가 있다면 가장 좋아요! 휴대폰 녹음 파일을 주시면 제가 다듬어요)
- **버튼·UI 효과음**: 지금의 합성음을 다듬어 써도 충분해요.
