# 🐶 멍뭉고치

강아지를 돌보고, 멍뭉 학교에 보내고, 친구 집에 놀러 가는 **웹 브라우저 힐링 돌봄 게임**입니다.
초등학교 4학년 친구들이 링크 하나로 바로 플레이할 수 있도록 만들었어요.

## 빠르게 실행하기

```bash
npm install
npm start            # http://localhost:3000
```

- Node.js **22.5 이상**이 필요해요 (내장 SQLite `node:sqlite` 사용, 별도 DB 설치 불필요).
- 개발 중에는 시간이 60배 빠르게 흐르는 모드를 쓰면 편해요: `npm run dev`
  (30분 학교 수업이 30초, 성장에 필요한 3일이 1시간 12분)
- 테스트: `npm test`
- 스프라이트 확인용 개발 페이지: `http://localhost:3000/dev/sheet.html` (`?s=6&b=corgi,shiba` 로 확대/견종 선택)

### 환경 변수

| 이름 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `3000` | 서버 포트 |
| `DB_FILE` | `data/meongmung.db` | SQLite 파일 위치 (영구 디스크에 두세요) |
| `GAME_SPEED` | `1` | 게임 시간 배속 (테스트용) |
| `TRUST_PROXY` | (없음) | 프록시/로드밸런서 뒤에서 실행할 때 `1` |
| `ADMIN_CODE` | (없음) | 운영자 신고 확인 화면 `/admin` 코드 (없으면 화면이 꺼져 있어요) |
| `CONTACT_EMAIL` | (없음) | 개인정보처리방침(`/privacy`)에 보일 문의처 |
| `BACKUP_DIR` | DB 옆 `backups/` | 하루 한 번 DB 백업 위치 (`BACKUP_KEEP`: 보관 일수, 기본 14) |
| `ORIGINAL_CODE` | (없음) | 스페셜 캐릭터 "👑 원조" 코드. 가족 계정이 내 정보 → "원조 코드가 있어요"에 입력해요 (스페셜마다 한 계정만) |

## 배포

### 자동 업데이트 (GitHub Actions + Watchtower)

코드를 올리면 GitHub Actions가 테스트 후 `ghcr.io/lmh925/moongchi:latest` 이미지를 만들어요.
NAS에서 `deploy/nas-compose.yml`처럼 이 이미지와 Watchtower를 띄워 두면 5분 안에 자동으로 새 버전으로 바뀌어요.
(데이터는 `moongchi_data` 볼륨에 그대로 남아요.)

### NAS / 집 서버 (Docker)

```bash
git clone https://github.com/lmh925/moongchi.git && cd moongchi
docker compose up -d --build     # http://NAS주소:3000
```

데이터는 `data/` 폴더에 쌓여요. 이 폴더만 정기적으로 백업하면 됩니다.
밖에서 접속하려면 NAS 관리 화면을 직접 열지 말고, **역방향 프록시 + HTTPS**(시놀로지 DDNS + Let's Encrypt)
또는 **Cloudflare Tunnel / Tailscale Funnel**처럼 게임 포트(3000)만 내보내는 방법을 쓰세요.

### 클라우드

단일 Node 프로세스 + SQLite 파일 하나로 동작합니다. Render, Fly.io, Railway 같은 곳에
**영구 디스크(볼륨)** 를 붙이고 `DB_FILE`을 그 디스크 경로로 지정하면 됩니다.

```
Build:  npm ci --omit=dev
Start:  npm start
Env:    DB_FILE=/data/meongmung.db  TRUST_PROXY=1
```

> 실시간 방(Socket.io) 상태는 서버 메모리에 있어서, 서버는 **1대(인스턴스 1개)** 로 운영하세요.
> 사용자가 많아져 여러 대가 필요해지면 Redis 어댑터와 Postgres로 옮기는 것을 권장합니다.

### 앱으로 설치 (PWA)
- `public/manifest.webmanifest`, `public/sw.js`, `public/icons/` (아이콘은 게임 픽셀 아트로 만들었어요).
- 안드로이드(크롬·삼성 인터넷): 타이틀 화면·내 정보의 "앱으로 설치하기" 버튼 → 설치 창.
- 아이폰(사파리): 같은 버튼이 "공유 → 홈 화면에 추가" 방법을 알려 줘요.
- 인터넷이 끊기면 `offline.html` 안내 화면. 게임 파일(`/v/<빌드>/…`)은 한 번 받으면 캐시에서 빠르게 열려요.
- HTTPS 주소에서만 설치돼요 (moongchi.thel.biz는 Cloudflare 덕분에 이미 HTTPS).
- 플레이스토어는 이 PWA를 TWA(PWABuilder/Bubblewrap)로 감싸서 올릴 수 있어요.

## 무엇이 들어 있나요

- **도입부 심리테스트** 5문항 → 성격 6종(잠꾸러기, 천방지축, 먹보, 애교쟁이, 수줍음쟁이, 똑똑이) × 견종 6종(비숑, 포메, 토이 푸들, 말티즈, 웰시코기, 시바견)
- **돌봄**: 밥주기 / 빗질하기(털이 뽕긋해지는 효과) / 쓰다듬기, 포만감·청결도·애정도
- **성장**: 아기 → 꼬마 → 늠름한 강아지 (경험치 + 함께한 날). 성장하면 몸이 커지고 털이 풍성해지며 개인기 선물과 새 아이템이 열려요
- **정면 모습**: 쉬다가 화면을 바라보고, 쓰다듬거나 빗질할 때 정면으로 돌아봐요. 초상화도 정면
- **터치 효과**: 강아지를 누르면 말랑 찌그러졌다 폴짝, 4번 연타하면 빙글! 바닥을 누르면 발자국 표시, 걸을 때 흙먼지
- **함께 등교(훈련 수업)**: 교실에서 선생님 명령에 맞춰 버튼을 눌러 훈련, 3번 성공하면 새 개인기를 바로 배워요
- **네컷 포토부스**: 내 강아지와 친구(또는 이웃집 초코)를 나란히 세우고 소품을 끌어다 씌운 뒤 찰칵! 네 컷 폴라로이드를 앨범(기기)에 저장
- **합동 줄넘기**: 밧줄이 발밑 선에 닿을 때 톡! 두 강아지가 같이 깡총, 콤보가 쌓일수록 빨라져요
- **멍뭉 놀이터 (공개 광장)**: 넓은 공원에서 누구나 만나요. 조이스틱/탭/방향키로 직접 조작, 채널당 20마리.
  놀이터 게임: 술래잡기, 멍멍 축구, 보물찾기 / 2인 협동: 대왕 리본 풀기, 실시간 줄넘기, 쿠션 탑 쌓기, 수제 간식 공장, 장난감 방 정리. 글자 채팅 없이 스티커·몸짓만, 차단/신고/입장 제한 (자세한 구조는 `docs/MULTIPLAYER.md`)
- **간식 파티**: 같은 방 친구들과 30초 실시간 간식 먹기 대결 (1등 보너스, 친밀도 UP)
- **캡슐 뽑기**: 하루 1번 무료, 등급(일반/레어/전설)과 확률 공개, 중복은 코인 환급 (현금 결제 없음)
- **멍뭉 학교 (혼자 보내기)**: 10분/30분/1시간/3시간 수업 → 알림장(도장, 선생님 한마디) + 새 개인기 + 코인, 언제든 **조퇴** 가능(다닌 만큼 보상)
- **강아지 친밀도**: 같은 방에 있기·쓰다듬기·같이 놀기로 오르는 5단계 (처음 만난 사이 → 영혼의 단짝)
- **개인기 9종**: 앉아, 손, 빙글빙글, 점프, 인사, 데굴데굴, 춤추기, 빵야, 노래하기
- **꾸미기**: 강아지 액세서리 24종(머리/목/얼굴), 방 가구 24종(벽지/러그/침대/장난감), 일부는 뽑기 전용
- **마이룸 & 소셜**: 친구 코드/초대 링크, 친구 집 방문, 실시간 이동·스티커·정해진 문장·채팅, 초대 알림
- **놀이터**: 쿠키런 스타일 달리기 **멍뭉 런**(2단 점프, 슬라이드, 체력, 하트 회복), 간식 받아먹기
- **소리**: Web Audio로 합성한 8비트 효과음(멍멍, 냠냠, 빗질, 코인, 성장 팡파르 등)과 배경음 2곡, 음소거 버튼 (소리 파일 없음)
- 모든 그래픽은 외부 이미지 없이 **코드로 그린 16비트 스타일 픽셀 아트**입니다 (`public/js/sprites.js`, `public/js/scene.js`)

## 아이 안전 설계

- 계정은 **닉네임 + 숫자 4자리**만 받아요. 실명·이메일·전화번호를 수집하지 않습니다.
- 비밀번호는 scrypt로 해시 저장, 5번 틀리면 10분 잠금, IP별 요청 제한.
- 친구는 **코드를 직접 주고받고, 상대가 수락해야** 맺어져요. 검색·랜덤 매칭 없음.
- 친구 집에만 놀러 갈 수 있어요.
- 글자 채팅은 **방 안의 모든 사람과 서로 친구일 때만** 열리고, 욕설·숫자 3개 이상·링크·SNS 아이디 유도 단어를 막아요.
  그 외에는 스티커와 정해진 문장으로만 대화해요.
- 강아지는 방치해도 **아프거나 떠나지 않아요** (수치는 20 아래로 떨어지지 않음).

## 폴더 구조

```
server/   Express + Socket.io 서버 (auth, game, friends, rooms, filter, db)
shared/   서버와 브라우저가 함께 쓰는 게임 데이터(data.js)와 규칙(rules.js)
public/   브라우저 클라이언트 (빌드 과정 없는 ES 모듈)
test/     node:test 테스트
docs/     기획 결정 사항
```
